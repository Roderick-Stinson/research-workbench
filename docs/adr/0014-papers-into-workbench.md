# ADR-0014：论文情报并入工作台，paper-cockpit 退役

- 状态：已接受（细节随后续问答补充）
- 日期：2026-10-11

## 背景
- 本人希望工作台除了管实验，还能：**自动检索相关领域的论文、每天推送、梳理 idea、挑中的论文用工作台复现**。
  参考了别人的"Paper 论文驾驶舱"截图（今日首页 / 前沿雷达 / 论文库 / 收藏 / IDEA / 研究设置）。
- 已有的 paper-cockpit（`<旧系统目录>`，8088 端口）覆盖了检索、排序、简报，
  但每日流程自 2026-09-04 起一直失败，5 周没有产出；种子库只有 8 月的 3 篇。

## 决策
1. **paper-cockpit 退役，代码、容器、镜像、数据全部删除**（本人决定；删除由本人执行，见下）。
   不迁移它的 12.6 万篇论文库、向量和种子；新模块从头建。
2. 论文相关功能**全部并入现有工作台**：同一个仓库、同一个数据目录、同一个面板、同一个写入口（`wb`）。

## 后果
- 工作台的范围从"实验记录"扩大为"研究工作台"：论文 → idea → 复现实验 → 论文 claim，是一条链。
- ADR-0011（面板只读、写操作走 agent）是否仍适用于论文侧，待定（截图里有"重新生成""立即获取"之类的按钮）。
- 检索来源、兴趣怎么定义、推送渠道、LLM 用哪家，待定。
