# ADR-0017：论文来源——全部都要

- 状态：已接受
- 日期：2026-10-11

## 决策
四路来源都接，统一按研究方向（ADR-0015）筛：
1. **arXiv 每日新提交**（cs.AI / cs.CL / cs.MA / cs.LG / cs.SE 等）；
2. **引用了种子论文的新论文**（Semantic Scholar 引文）——窄领域里最准的信号；
3. **顶会 / OpenReview**：录用论文与评审意见；
4. **GitHub**：领域内的新仓库 / 热门仓库（复现的代码来源）。

同一篇论文在多个来源出现时合并为一条（arXiv ID > DOI > 归一化标题），来源作为证据保留。

## 实现默认（非本人决策，可改）
- 打分 / 摘要用的 LLM 复用 `baseline/.secrets/` 下已有的 API 配置，默认便宜模型批量筛、少量精读；
  模型名写在工作台 config.json，不写死在代码里。
