# ADR-0036：本人评价论文，据此重排每日精选、更新画像

- 状态：已接受
- 日期：2026-10-12

## 背景
本人希望在论文库和每日精选里给论文写评价，并让评价影响画像和以后推送的论文——有些论文属于方向、质量分也不低，但本人认为很差
（例如 Recursive Self-Improvement through Multi-Agent Self-Supervision）。"不相关"只能表达"不属于方向"，表达不了"属于方向但不好"。

## 决策
1. **评价**：1–5 分（1 很差 · 2 差 · 3 一般 · 4 好 · 5 很好）+ 一句理由（尽量用本人原话），存在论文的 status.json（`rating`），改动进 history 与流水账。
   面板仍然只读：论文页有"我的评价"区（当前评价 + 复制指令按钮），卡片上显示评价，论文库可按评价筛选 / 排序；写入由 agent 执行 `wb paper rate`。
2. **自动影响精选**：精选先按原分数（质量 + 关注度 + 种子 + 代码 / 录用）取 max(30, 3×名额) 篇候选，再由批量模型对照
   "评价过的论文 + 理由"和画像里的口味，给每篇候选打"本人会不会喜欢"（0–1），总分 = 0.6 × 原分数 + 0.4 × 喜欢程度（`selection.taste_weight`）。
   推送和面板上写出"按你的评价"的理由。评价少于 3 条或额度不够时不重排，不影响出刊。
3. **画像（确认后生效）**：画像新增"口味"（taste：likes / dislikes）。上次画像修改以来新评价攒够 3 条，每日流程的 `profile` 步骤自动起草修改
   （方向描述 / 子主题 / 检索词 / 口味，依据含评价与理由），推送里提示；本人确认后 `wb field apply` 才写入（沿用 ADR-0033）。
4. 构思用的论文库带上评价，评价 ≤ 2 的论文不作为方法依据。

## 后果
- 评价立刻作用于下一次精选（直接作为例子），而画像的文字修改要本人点头——口味不会被一两条评价悄悄改掉。
- 重排每天多一次批量模型调用（约 30 篇候选）。
