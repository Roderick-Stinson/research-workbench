# ADR-0040：顶会顶刊必读清单

- 状态：已接受
- 日期：2026-10-13

## 背景
本人要求：研究方向内发表在 CCF-A、TPAMI、子刊上的论文，找出必读的，按时间排序。
核查：论文库只回填了近 12 个月的 arXiv（2,474 篇属于方向的论文里 2024 年及以前只有 10 篇），领域经典（MetaGPT、AgentVerse、GPTSwarm、
AFlow、ADAS、MaAS、G-Designer、AgentPrune……）大多不在库里；已有的录用信息只有 326 篇，且从 arXiv 评论解析得很粗（"the"、"IEEE"、研讨会混在一起）。

## 决策
1. **识别顶会顶刊**（`venues.py`）：CCF-A 会议 / 期刊（含 TPAMI、IJCV、JMLR、TOSEM、TKDE……）、ICLR（CCF 目录未收录，但公认顶会，单独标注）、
   Nature / Science 及子刊。研讨会、Findings、companion / demo / tutorial、"under review / submitted to" 都不算。
   S2 不区分 ACL 主会与 Findings，用 ACL Anthology 的 DOI（findings-acl / acl-long）区分。来源优先级：S2 > arXiv 评论 > 速读里作者自称。
2. **发现**：用 Semantic Scholar 的批量检索，按方向关键词 × 顶会顶刊（2023 年起）找论文；新论文进库（标 backfill，不进每日精选），
   走相关性判定与速读（回填预算）。库里属于方向的论文每 14 天核对一次录用信息。
3. **必读** = 属于方向 + 顶会顶刊 + 至少一条：种子论文 / 领域常用方法的原论文 / 被论文库里 ≥ 3 篇论文当作对比方法 /
   引用数高（发表满一年 ≥ 50，不满一年 ≥ 20）。其余顶会顶刊论文为**值得读**，过口味过滤（ADR-0039）；必读不过口味过滤（经典要读）。
   评价 ≤ 2、标为不相关的不进。按发表时间排序（面板可切换新 → 旧 / 旧 → 新、按会议档次筛选）。
4. 每日流程的"报告"步骤重建清单；每周一重新检索。面板新增"必读"页，CLI `wb topvenue run | ls`。

## 后果
- 论文库会多出一批 2023 年以来的顶会论文（判定属于方向的才速读），领域地图、结果表也因此更完整。
- 关键词检索不可能穷尽；"必读"依赖论文库里的对比关系与引用数，新录用的论文多半先出现在"值得读"。
