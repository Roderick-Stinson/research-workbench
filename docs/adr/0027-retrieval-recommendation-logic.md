# ADR-0027：检索与推荐逻辑参考 AI Safety HOT（只借逻辑，不借内容）

- 状态：已接受
- 日期：2026-10-11
- 参考：https://aisafetyhot.com 、https://github.com/wuyoscar/AISafetyHot-Hub（该仓库只有内容导出与 MCP 说明，没有网站源码；
  逻辑取自其 status.json、docs/agent.md、导出 JSON 字段与网站行为）。领域不同：我们是 MAS 架构优化，不是 AI 安全。

## 借鉴的逻辑
1. **收录与精选分两层**
   - **收录**只判"是否属于研究方向"（ADR-0015），**不评好坏**；收录的每篇都有速读（问题 / 方法 / 实验与结果 / 局限与可以继续做的 / 实验设置）和维度标签。
   - **精选**（每日推荐，≤10，ADR-0020）从收录里按分数挑；精选的每篇再做 8 步精读（ADR-0019）。
2. **分数 = 质量 + 关注度**：关注度来自独立来源的讨论（HF Daily Papers 点赞、Reddit、Hacker News、X 等），
   按近 72 小时内独立来源数、讨论链接数和 24 小时走势计算；质量来自 LLM 评估（相关性、新颖性、严谨性、是否开源 / 被录用）。
3. **去重**：同一篇论文（arXiv ID > DOI > 归一化标题）只留一条；保留优先级：精选 > 分数高 > 收录早。
4. **一日一期，当天可更新**：期号按北京时间；窗口为前一天 08:00 至当期最后更新；08:30 发第一版（ADR-0026 默认），
   之后新进展（新版本、代码放出、被录用、讨论升温）更新**同一期**，不另开一期。
5. **两种排序**："已整理优先"（有精读 / 已归类的在前）与"最新发表"，都不代表质量排名。
6. **来源**：在 ADR-0017 四路之外加 **HF Daily Papers**，以及作为关注度信号的 Reddit / Hacker News / X。
7. **透明与时效**：每期记录生成时间、读取各来源的时间、各步骤状态；AI 生成的摘要都标"以原文为准"。

## 一并决定（Q17）
- **跨论文结果表**：从每篇的"实验设置"里抽取 任务 / backbone / 指标 / 报告数值（带出处：论文 + 表号），
  汇成"方法 × benchmark"对比表；它也是复现参照数字（ADR-0023）的来源。
- **周报 / 月报 + 热点榜**。
- **只读 MCP**：本机或其它机器上的 Claude / codex 都能查论文库、领域地图、IDEA、结果表。
- 不做：BibTeX 导出。

## 理解确认
本人回答 Q16 时说"参考它的检索及推荐逻辑"。它的逻辑正是"收录只看相关性 + 精选按分数"的两层结构，所以按两层执行；如理解有误请指出。
