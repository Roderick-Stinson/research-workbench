# ADR-0019：每篇推荐论文都有 short summary + paper-explainer 8 步精读

- 状态：已接受
- 日期：2026-10-11

## 决策
- 每天推荐的**每一篇**论文都生成：
  1. short summary（推送和列表里用）；
  2. 按 paper-explainer 完整 8 步的精读 HTML（读全文，带图）。
- 精读 HTML 同时是"问题 Problem"的证据来源（ADR-0018）：聚合多篇论文发现问题时，直接引用这些 HTML 里的原文和数字。

## 后果
- 每日流程里最重的一步：每篇需要一个 agent 读全文、作图，按篇并行、失败单篇重试，不影响其它篇和推送。
- 每天推荐多少篇、由哪个 agent / 模型来写，决定了耗时和花费（见后续决策）。
