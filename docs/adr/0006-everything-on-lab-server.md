# ADR-0006：全部部署在实验室服务器，云主机暂不使用

- 状态：已接受（取代最初"部署在云主机"的设想）
- 日期：2026-10-11

## 背景（2026-10-11 实测）
- 实验室服务器（校园内网，登录 shell 是 zsh）→ 云主机：HTTP 80 **直连**返回 200；**走实验室服务器的代理**返回 502；22 端口直连超时。
- 云主机 → 实验室服务器：内网地址，访问不到。
- 云主机：Debian、6G 内存（可用约 2.7G）、剩 60G 磁盘，已经跑着十来个容器。
- 代码快照和 checkpoint 只能放在实验室服务器（体积大，ADR-0003/0004）。

## 决策
记录、产物、面板**全部放在实验室服务器**。面板参照 paper-cockpit 的方式用 docker compose 部署，
直接读取文件系统上的 Run 记录，**不做任何跨机器同步**，只有一份数据。

## 后果
- 面板只能在校园网 / VPN 内访问（同 paper-cockpit，`http://<lab-server>:8765:<port>`）。
- 以后需要外网访问时：把云主机只当反向代理入口（frp 走 80/443，加登录鉴权，**不存数据**）。
  这是叠加上去的，不改动本架构。
- 如果以后加这个入口：实验室服务器上的客户端必须设置 `NO_PROXY`，否则会被本机代理拦截。
