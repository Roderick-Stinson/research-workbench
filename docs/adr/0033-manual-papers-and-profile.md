# ADR-0033：本人手动提供论文、据此更新画像、"不相关"作为反例

- 状态：已接受
- 日期：2026-10-12

## 背景
本人希望有时自己提供论文，用来更新研究画像；而当时既不能手动往论文库加论文，画像（方向描述 / 检索词）也不会随论文变化，
"不相关"标记也只是不再推这一篇。

## 决策
1. **`wb paper add <arXiv号 | 链接 | 标题 | 服务器上的 PDF>`**：直接进库（来源"本人提供"，不再判相关性），立刻速读；
   `--seed` 同时设为种子（需要 arXiv 号），`--explain` 顺带 8 步精读。本人提供的论文**不进每日精选**，但参与领域地图、结果表、构思与画像。
   PDF 留在论文目录，全文从它抽取；标题用 Semantic Scholar 匹配补全元数据。
2. **画像更新两步走**：`wb field suggest` 由批量模型根据种子 + 本人提供的论文（正例）+ 标为不相关的论文（反例）起草
   新的方向描述、子主题、arXiv 检索词，存为 `registry/field.proposed.json`；**本人确认后** `wb field apply` 写入，旧版本留在 `registry/field.history/`。
3. **"不相关"作为反例**：最近 30 篇标为不相关的论文（含备注原因）写进相关性判定的提示，以后少收同类论文。

## 后果
- 画像的改动会影响以后抓哪些论文、怎么判相关；所以必须先给本人看建议，不自动生效。
