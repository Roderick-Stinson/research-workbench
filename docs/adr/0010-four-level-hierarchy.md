# ADR-0010：项目 → 实验（claim）→ 配置组 → Run 四层结构

- 状态：已接受
- 日期：2026-10-11

## 决策
- **项目 = 本人自己要写的一篇论文**，手动创建。下载的别人论文代码只是 baseline，不是项目。
- **实验 = 论文里的一个 claim**，手动创建，带 claim 描述。
- **配置组（Variant）= 聚合单位**：方法 × 参数 × 任务固定，Run 之间只有种子不同。均值 ± 标准差在这一层计算。
- **配置组和实验是多对多关系**：同一个配置组（例如 baseline × hotpotqa）可以同时支撑多个 claim，不重跑，也不重复认领。
  论文里的每个数字因此只有一个来源。
- **Run 只属于一个配置组**；认领之前不属于任何项目（待认领）。
- **工作目录（<watch_root>/<dir>）与项目是正交的**，只作为 Run 的一项属性记录，不参与分类。

## 对其它 ADR 的修订
- ADR-0005 里"Experiment 显式声明 / 同组算均值"的"组"，按本 ADR 指的是**配置组**。
