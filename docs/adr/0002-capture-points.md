# ADR-0002：两个记录挂载点

- 状态：**已被 ADR-0009 取代**（本人不想改启动方式；保留此文档作为决策历史）
- 日期：2026-10-11

## 背景
实验有两种启动方式（见 CONTEXT.md）：探索阶段由 cc / codex 启动，正式阶段由自己写的脚本启动。
ADR-0001 要求记录不能靠人记得。

## 决策
1. **探索阶段**：在 `<watch_root>/CLAUDE.md` 和 `AGENTS.md` 里写规则，agent 启动实验前登记目的和参数，跑完回填结果。
   "记得去记"这件事交给 agent。
2. **正式阶段**：记录器以几行代码的形式写进实验脚本或入口；**每个脚本只需要接一次**，之后每次运行自动记录。
3. 兜底：工作台列出"有 GPU 进程或输出目录、但没有登记"的实验（具体做法待定）。

## 后果
- 记录接口必须同时提供 CLI（给 agent 和 shell 用）和 Python API（给脚本用）。
