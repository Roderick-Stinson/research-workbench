# ADR-0038：HF Daily 单独一栏（只放属于研究方向的）

- 状态：已接受
- 日期：2026-10-13

## 背景
本人反馈推给他的大多是 arXiv 新论文，希望也推一些 Hugging Face Daily Papers。核查近 30 天：HF Daily 抓到 200 篇，
相关性判定属于"多智能体架构优化"的只有 7 篇（其余是扩散、机器人、视觉、推理服务等，判定无误），而这 7 篇都没和领域常用方法比较，
被精选的 baseline 门槛（ADR-0037）挡掉了。本人要求单开一栏，但仍要和方向一致，不放宽方向。

## 决策
1. 每日流程新增 `hf` 步骤（精选之后）：近 7 天上过 HF Daily、相关性判定属于方向、没进过精选、没在之前的栏里出现过的论文，按 HF 点赞取前 5 篇
   （`selection.hf_max_per_day`、`selection.hf_window_days`）。
2. 这一栏不算精选：不过 baseline 门槛与中稿评估，不做精读（只有速读）；但写明是否和领域常用方法比较过、用了哪些常用 benchmark，让本人自己判断。
3. 推送和面板每期页面都有这一栏；标为不相关、评价 ≤ 2、或重新精选时被换掉的论文不进（不把刚被筛掉的论文从侧门推回来）。

## 后果
- 不改变精选的严格程度，也不放宽研究方向；HF 上的热门论文按方向过滤后单独展示。
- 本方向的 HF 论文本来就少（近 30 天 7 篇），有些天这一栏会是空的。
