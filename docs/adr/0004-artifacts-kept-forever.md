# ADR-0004：产物永久保留，只能显式删除

- 状态：已接受
- 日期：2026-10-11

## 决策
- 每个 Run 的产物（checkpoint、LoRA、中间 step 等）**全部永久保留**，存放在归属于这个 Run 的目录 `runs/<RUN-ID>/`。
- Run 结束后，产物目录设为只读，防止后续实验覆盖。
- 工作台**没有任何自动清理**。只有本人明确指定某个 Run 或某批 Run"不需要了"，才执行删除；
  删除时保留 Run 记录本身，并标注"产物已删除（日期、谁删的）"。

## 后果
- 实验数据盘是共用盘（2026-10-11：7.0T，已用 84%，剩 1.2T）。面板必须显示：各项目和各 Run 的产物占用、数据盘剩余空间，
  空间偏低时醒目提示，但只提示，不动手。
