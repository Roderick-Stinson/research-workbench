# ADR-0020：每日篇数看质量（≤10），精读由 codex 执行（可换后端），推荐论文要做 related work 式梳理

- 状态：已接受
- 日期：2026-10-11

## 决策
1. **篇数**：按当天找到的论文质量决定，**每天最多 10 篇**；质量不够可以少于 10，也可以为 0。
2. **执行者**：精读（读全文、作图、写 HTML）由 **codex** 非交互执行。后端未定：ChatGPT 订阅，或第三方 API 提供的 GPT 模型。
   → 执行命令做成配置（命令模板 + 模型 + provider），不写死；换后端只改配置。
3. **Related work 式梳理**：对**所有推荐过的论文**（含种子 / baseline）持续做分类和梳理，像论文的 Related Work 一节：
   分几类、每类的核心思路、代表工作、这一类没考虑到什么。新论文每天归入，分类结构随论文增多而调整（具体形式见后续决策）。

## 后果
- "这一类没考虑到什么"是发现**问题 Problem**（ADR-0018）的天然入口。
