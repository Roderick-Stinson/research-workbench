# ADR-0021：Related work 梳理 = 多维度 + 一个主分类

- 状态：已接受
- 日期：2026-10-11

## 决策
- **主分类**（默认按"优化什么"：prompt / agent 角色 / 通信拓扑 / workflow 代码 / 整体流水线）
  写成 Related Work 文体：每类的核心思路、代表工作（带引用）、**这一类没考虑到什么**。
- **其它维度**作为标签与矩阵（论文 × 维度）：搜索方式（MCTS / 进化 / RL / 可微超网 / LLM 生成）、
  粒度（任务级固定架构 vs 查询自适应）等。维度集合可增减。
- 新论文**每天**由 agent 归类；分类结构的重组（拆 / 合类）**最多每周一次**；
  **每个版本都保留**，可以回看领域分类怎样演化。

## 理由
单棵树只能表达一个维度，跨类论文会被硬塞；版本保留让"领域在怎么变"可见。
