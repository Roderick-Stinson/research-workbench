# ADR-0011：面板只读，所有写操作走 agent

- 状态：已接受
- 日期：2026-10-11

## 决策
- 网页面板**只读**（与 paper-cockpit 的"网页只读，输入在 Obsidian"保持一致）。
- 建项目、建 claim、认领、写结论、删产物，**全部通过 codex / cc 调用同一个 `wb` CLI 完成**。系统只有一个写入口。
- 面板提供"复制指令"按钮：生成一句自然语言指令（例如"把 RUN-xxx 认领到 论文A / claim 2 / Ours×hotpotqa"），粘贴给 agent 执行。
- 无需登录鉴权（校园网内）；以后开放外网入口时（ADR-0006），只读面板的风险也小。

## 信息架构（Q13）
- **首页**：只有两块：①我的项目（论文）列表；②待认领收件箱（数量醒目）。外加一行磁盘占用（ADR-0004）。
- **项目页**：所有细节都在这里：claim 列表 → 每个 claim 下的配置组对比表（均值 ± 标准差、n、一致性警告）→ Run 详情
  （命令、参数、代码 diff、日志、曲线、关联对话、产物、还原命令）。
