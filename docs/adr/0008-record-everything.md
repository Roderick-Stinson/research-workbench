# ADR-0008：结果"有什么记什么"，不预设格式

- 状态：已接受
- 日期：2026-10-11

## 决策
- **Run 目录就是记录本身**：实验写进 Run 目录的所有文件（指标、曲线、逐样本输出、轨迹、图……）全部保留（配合 ADR-0004 永久保存）。
- 工作台**自动**采集、不需要实验代码配合的部分：完整 stdout/stderr、退出码、起止时间和耗时、GPU 型号 / 显存 / 利用率曲线、主机名、崩溃时的报错尾部。
- 唯一需要结构化的是**指标**（标量和按 step 的序列），因为要拿来算 Repeat 的 均值 ± 标准差、画曲线、做对比。
  成本（token / 美元 / GPU 小时）当普通指标处理。
- 逐样本输出约定为 jsonl（每行一个样本，带稳定的 sample_id），面板可以跨 Run 对比"谁做对了哪些题"；不按约定写也照样保留，只是不能做对比。
