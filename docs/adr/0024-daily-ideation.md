# ADR-0024：每天主动想多个 IDEA，评估后只告诉本人"够 CCF-A"的；告诉过的只有本人说删才删

- 状态：已接受
- 日期：2026-10-11
- 关系：细化 ADR-0018（问题 → IDEA）

## 决策
1. **不设时间限制**：agent **每天**根据手里的全部内容（论文与精读、领域地图、问题、复现结果、实验与 bad case）想**多个** IDEA。
2. 每个 IDEA 都要经过**质量评估**；够不上 **CCF-A 类会议**水平的，**不告诉本人**。
3. 告诉本人的 IDEA（连同它针对的问题 Problem 的 HTML 和 IDEA 的 6 步 HTML，ADR-0018）**永久保留**，
   **只有本人明确说删除才删除**（与 ADR-0004 同一原则）。

## 待定

- 没通过评估的 IDEA 是否留存（用于去重，避免第二天又想出同一个）。
