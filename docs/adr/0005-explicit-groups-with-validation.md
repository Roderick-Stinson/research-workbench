# ADR-0005：配置组显式声明，工作台自动校验（"组"指配置组，见 ADR-0010）

- 状态：已接受
- 日期：2026-10-11

## 决策
- 一个 Run 属于哪个 Experiment，由**本人或 agent 显式声明**（在脚本或命令里写 `experiment="xxx"`），工作台不自动推断。
- 同一 Experiment 下的 Run 就是它的 Repeat，面板展示 均值 ± 标准差（以及 n、每个种子各自的值）。
- **自动校验**：组内 Run 的代码快照哈希，或"去掉种子字段后的配置哈希"不一致时，面板醒目警告，并展示具体的代码或配置 diff。
  只警告，不拒绝，也不自动拆组。
- 哪些字段算"种子"（seed / data_seed / shuffle_seed …），每个项目声明一次。

## 理由
本人选择显式命名，便于掌控和在论文里引用；自动校验用来防止 agent 在两个种子之间悄悄改了代码。
