# ADR-0025：IDEA 由独立审稿人评估：两票否决 + 均分门槛

- 状态：已接受
- 日期：2026-10-11

## 决策
- 评估由**独立审稿人**完成：与提出 IDEA 的 agent 是不同会话、不共享上下文，按 NeurIPS / ICLR 审稿人的标准审。
- **一票否决 ①新颖性**：检索 arXiv / Semantic Scholar + 本地领域地图，已有人做过即否决（附撞车论文）。
- **一票否决 ②问题真实性**：针对的问题必须有真实证据（论文原文 / 数字，或真实 bad case），不能是想象出来的。
- **打分 1–10**：重要性、新颖性、技术深度、在本地资源（6 张 GPU + API 预算）下的可行性；并列出审稿人最可能提的主要弱点。
- 两票都过且**均分 ≥ 7** 才告诉本人，审稿意见随 IDEA 一起给。

## 实现默认（非本人决策，可改）
- 没通过的 IDEA 不告诉本人，但**留存在隐藏区**（带审稿意见），用于去重，避免第二天想出同一个；本人可以随时让 agent 翻出来。
