# ADR-0001：记录不能依赖"记得去记"

- 状态：已接受
- 日期：2026-10-11

## 背景
2026-08 已经建好 explog + lab-template（设计冻结，测试全绿），但 explog-repo 最后一次提交停在 2026-08-19，
之后的项目（如 <项目 A>）一次都没接入。本人确认原因是**忘了 / 没养成习惯**，不是工具不好用，也不是太重。

## 决策
新工作台的首要验收标准：**实验跑起来时，即使不主动想起，也会被记下来**。
人工要做的事（写目的、写结论）必须由工作台**主动催**，而不是靠人自己记得。

## 后果
- explog 的数据模型（Experiment / Run / Repeat）可以沿用，要改的是"记录怎么触发"。
- 网页面板除了展示结果，还要担任"催收尾"的角色：列出没写目的、没写结论的实验。
